## With no account

`bw status`, three runs: 1.47 s, 1.26 s, 1.26 s. It prints `{"serverUrl":null,"lastSync":null,"status":"unauthenticated"}`.

`bw serve --hostname unix://<path>` prints "You are not logged in." on standard error and exits 1. It never listens, so nothing about the socket could be measured without an account: not the envelope, not origin protection, not `/generate`.

`bw unlock --raw` and `bw list items` answer "You are not logged in." and exit 1. `bw login <email> --passwordenv <unset name>` with `BW_NOINTERACTION=true` answers "Master password is required." without asking.

`bw generate -uln --length 20` and `bw generate --passphrase --words 4 --separator - -c --includeNumber` both work logged out, as one-shot commands.

`/opt/homebrew/bin/bw` is a script whose first line is `#!/opt/homebrew/opt/node/bin/node`. That node is ad-hoc signed with `flags=0x2(adhoc)`: no hardened runtime, no team.
